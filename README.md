# BMI Calculator

## Description
BMI Calculator is a beginner-friendly Python command-line application that calculates Body Mass Index (BMI) using a user's height and weight. It displays the BMI value and classifies it as Underweight, Normal Weight, Overweight, or Obese.

## Features
- Calculates BMI accurately
- Accepts user input for height and weight
- Displays BMI value
- Classifies BMI into health categories
- Simple command-line interface

## Technologies Used
- Python 3

## BMI Formula
BMI = Weight (kg) / (Height × Height)

## How to Run

1. Install Python 3.
2. Download the project.
3. Open the project folder in VS Code.
4. Run:

```bash
py CALCULATOR.py
```

## Example

```
Enter your weight (kg): 65
Enter your height (m): 1.75

Your BMI is: 21.22
Category: Normal Weight
```
